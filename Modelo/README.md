# Modelo de Machine Learning

Este directorio contiene los archivos del modelo entrenado necesarios para que la aplicación funcione.

## Archivos requeridos:
- `Modelo.joblib` - Modelo pre-entrenado de Machine Learning
- `scaler_X.joblib` - Normalizador RobustScaler para datos de entrada

## Nota importante:

Si clonaste este repositorio desde GitHub y los archivos `.joblib` no están presentes:

1. Los archivos son demasiado grandes para almacenar en GitHub
2. Debes obtenerlos de la fuente original o contactar al autor
3. Coloca los archivos en esta carpeta (`Modelo/`) para que la aplicación funcione

Sin estos archivos, la aplicación mostrará un error al intentar cargar el modelo.
